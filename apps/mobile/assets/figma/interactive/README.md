# Interactive Architecture artwork

These PNGs are the actual **Parkey approved illustration** assets exported with
Figma MCP on 2026-11-17 from the owner's Parkey design file
`UaU1KMJV2tMlwGB7Y1Co1g`, page `244:2804`:

| Asset        | Light / dark source frames | Use           |
| ------------ | -------------------------- | ------------- |
| discover.png | 249:1662 / 249:5091        | Walkthrough 1 |
| compare.png  | 249:1688 / 249:5117        | Walkthrough 2 |
| navigate.png | 249:1714 / 249:5143        | Walkthrough 3 |

They are bundled locally, never loaded through temporary Figma asset URLs.
Their use is limited to the owner-authorized Parkey implementation; this
repository grants no separate license to redistribute the owner's artwork.
The comparison artwork is explicitly labelled as illustrative example rates
and distances. It supplies no operational parking facts.
Official logos retain their original colors. Outfit's existing font license
remains alongside the bundled fonts.

`parking-marker.png` and `parking-marker-selected.png` rasterize the Figma 22
marker UI at 3×: 42×50 logical pixels, a magenta rounded marker, white circular
inset and an Outfit ExtraBold P. Geometry is from frame `249:3020`, marker
`249:3040`; the selected variant adds a white outline for map contrast. These
are UI symbols, not replacements for the official Parkey logo. All parking
uses the same marker; a source fee never becomes a vacancy indicator.

The official P is the unmodified approved vector from About frame `249:4563`
(asset layer `8581e.svg`), rasterized locally for native and web. Its original
magenta and teal fills stay fixed across themes. The welcome wordmark follows
frame `249:4141`: Baloo 2 ExtraBold, magenta arkey lettering beside that P.
`Baloo2-variable.ttf` comes from google/fonts `ofl/baloo2`, with its bundled
SIL Open Font License; it generates this static wordmark, not application UI text.
All application UI typography remains Outfit.

Dark entry screens select the original white/teal P supplied by Figma frame
`249:7580` (asset `b2941.svg`); their wordmark uses its supplied white lettering.
Profile/Saved/About retain the fixed magenta/teal approved P in both modes,
as shown by their paired frames. No tint or runtime recoloring is applied.
