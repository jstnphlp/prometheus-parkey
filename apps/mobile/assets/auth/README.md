# Provider artwork

`google-g.png` is Google's unmodified G artwork from
https://developers.google.com/identity/images/g-logo.png, retrieved for the
Continue with Google button. The white button follows Google's light treatment.
The Facebook f mark is rendered as a vector in `src/auth/social-buttons.tsx`.
These trademarks identify the corresponding providers; they are not Parkey artwork.
No remote artwork URL is requested by the installed app.
