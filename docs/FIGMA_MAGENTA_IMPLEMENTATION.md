## Reuse and integration decisions

- Retain both Explore and pilot runtime branches, MapLibre native/web, current record sources, public-cache isolation, source qualification, licensed-photo fallbacks, entrance refresh, route consent, local saved records and private-report gates.
- One ThemeProvider owns both modes. Existing entry/discovery color names are semantic adapters to this same model; styles subscribe via cached per-mode hooks. Outfit assets and their existing licenses are reused.
- Appearance is available as an inline sheet during discovery/details/search so changing colors keeps the map instance, selection, search draft, navigation and unsent forms mounted. The standalone Appearance route reuses the same choices.
- Account code on this branch predates this task: Supabase email signup/login, PKCE confirmation/recovery, remember preference, secure storage and build-flag/provider-gated OAuth. Preserve those real code paths and their release gates; no new backend wiring or fake success.
- The new profile settings do not collect vehicle or questionnaire data. Personal information is read only from a real session. Language is English only; help is local FAQ, not an outbound support service.
